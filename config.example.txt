  - Localização do arquivo de configuração (Linux/Mac)
  - Windows: %APPDATA%\Claude\claude_desktop_config.json

  - Nome do servidor MCP para NotebookLM

--- CONTEÚDO DO claude_desktop_config.json ---

  "mcpServers": {
    "notebooklm": {
      "command": "notebooklm-mcp-server",
      "args": []
    }
  }
}

--- VARIÁVEIS DA SKILL CLAUDE CODE ---
CAMINHO_SKILL: ~/vault/.claude/CLAUDE.md
  - Localização do arquivo de skill no seu vault
  - Windows: C:\Users\[SeuUsuario]\vault\.claude\CLAUDE.md

DIRETORIO_RESEARCH: ~/vault/research/
  - Diretório onde as notas de pesquisa serão salvas
  - Windows: C:\Users\[SeuUsuario]\vault\research\

FORMATO_DATA: YYYY-MM-DD
  - Formato da data no nome do arquivo

FORMATO_NOME_ARQUIVO: YYYY-MM-DD-{tema}.md
  - Padrão de nomeação dos arquivos de pesquisa

--- ESTRUTURA DA NOTA NO OBSIDIAN ---
FRONTMATTER:
---
tags: [pesquisa, notebooklm]
data: YYYY-MM-DD
fontes: []
status: rascunho
---

SEÇÕES OBRIGATÓRIAS:
- ## Conceitos-chave
- ## Pontos de atenção

--- COMANDO DE EXECUÇÃO ---
notebooklm ask --new --json "Quais são os pontos centrais sobre {tema}?"
